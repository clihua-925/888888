## 一、冻结架构边界（任何阶段禁止修改）

| 项 | 内容 |
|---|---|
| 五层架构 | WebUI/API → Orchestration Agent → Business → Contract/Runtime/State → Infrastructure |
| 业务节点 | 固定 9 个：PRODUCT_DEFINITION / TRADE_STRATEGY / CUSTOMS_NODE_COLLECTION / TRADE_EDGE_BUILD / EVIDENCE_VERIFY / ENTITY_RESOLUTION / GRAPH_EXPANSION / RESOURCE_CLASSIFICATION / DATABASE_COMMIT |
| 业务节点禁止 | 路由、retry、timeout、调度、恢复、checkpoint 生命周期 |
| 唯一路由 | Condition Edge Engine（core/orchestration/conditions.py） |
| 恢复机制 | RecoveryManager 通用化，禁止硬编码业务节点 ID |
| Runtime 依赖传递 | contextvars（core/orchestration/runtime.py），禁止写入 state["orchestration"] |
| 数据库写入 | 只有 DATABASE_COMMIT 一处，通过注入的 Database |
| AI 调用 | DecisionLayer + ReasoningEngine，JSON Schema 输出，禁止 Function Calling / Tool Calling |
| LangGraph checkpoint | SqliteSaver，路径 data/checkpoints.db |

- mission

- node_reports

**4 个 envelope 字段**：
- status

- workflow_version

**禁止**：新增、删除、改名、修改类型。

## 三、LangGraph API 冻结

### StateGraph 构造

```python
graph = StateGraph(state_schema=TaskState)
```

### Conditional Edge

router 返回值 = node_id 或 END

mapping：

```python
targets = {node_id: node_id for node_id in plan.order}
targets[END] = END
```

### SqliteSaver 导入

```python
from langgraph.checkpoint.sqlite import SqliteSaver
```

### invoke

```python
graph.invoke(state, config)
```
